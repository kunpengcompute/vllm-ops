# vLLM高版本特性回合主补丁包

本目录包含将vLLM 0.18.0、0.19.0、0.20.0的核心性能优化及稳定性特性回合至vLLM 0.17.0的文件级补丁合集，共85个补丁。

## 目录说明

| 文件 | 说明 |
| --- | --- |
| `0001-*.patch` ~ `0085-*.patch` | 文件级回合补丁，命名为`<序号>-<目标文件路径>.patch`（文件名中`__`对应源码路径分隔符`/`）。 |
| `series` | 补丁应用顺序，按序号0001~0085排列。 |
| `manifest.csv` | 补丁与目标源文件的映射，格式为`patch,source_file`。 |

补丁覆盖源码目录：`vllm/`（59个）、`tests/`（22个）、`benchmarks/`（2个）、`docs/`（2个）。

## 应用方法

补丁在源码编译前合入vLLM 0.17.0源码树，随后源码安装生效。完整流程参见[用户指南](../../docs/zh/user_guide.md)。核心步骤如下：

```bash
cd <vLLM 0.17.0 源码根目录>
while read -r p; do
    patch -p1 --forward < <本目录绝对路径>/$p
done < <本目录绝对路径>/series
```

补丁合入时若无`FAILED`或`Hunk`失败等特殊回显信息，则合入成功。回合特性明细参见[特性介绍](../../docs/zh/feature_introduction.md)。
